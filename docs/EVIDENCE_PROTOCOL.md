# Evidence Protocol

## Purpose
Make it easy to distinguish known facts, estimates, candidates, and unresolved claims.

## Evidence levels
- VERIFIED — checked against a direct or authoritative source.
- ESTIMATE — calculated or approximated; never presented as confirmed fact.
- RESEARCH CANDIDATE — interesting but not cleared for testing.
- NEEDS LIVE VERIFICATION — a critical current claim is missing.
- REJECTED — fails a defined requirement or has a documented blocking risk.

## Source hierarchy
1. Supplier/product listing
2. Official platform documentation
3. First-party trend/market data
4. Reputable secondary sources
5. Community discussion as qualitative context only

## Audit requirements
For each critical claim retain the claim, source URL, source type, date checked, verification status, and notes.

Missing evidence must never be converted into a positive assumption.
