# Product Research Record

| Field | Description |
|---|---|
| Product Name | Clear product name |
| Status | Candidate / Needs Verification / Rejected / Ready for Test |
| Customer Problem | The concrete problem solved |
| Demand Evidence | Source-backed demand signal |
| 12M Trend | Recent trend behavior |
| 5Y Trend | Long-term context |
| Seasonality | Relevant seasons/events |
| Supplier | Supplier/source name |
| US Warehouse | Verified yes/no/unknown |
| Delivery | Verified estimate |
| Product Cost | Supplier product cost |
| Shipping | Shipping cost |
| Suggested Retail | Test selling price |
| Gross Profit | Revenue minus landed cost before other expenses |
| Gross Margin | Gross profit / revenue |
| Competition | Low / Medium / High with evidence |
| Ad Potential | Explanation, not just a score |
| Risk | Main operational risks |
| Source | Direct source URL |
| Verified At | Date/time of verification |
